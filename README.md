## Numpy

--NumPy, short for Numerical Python, is the foundational open-source Python library used for scientific computing, data science, and machine learning. 

--Created by Travis Oliphant in 2005, it introduces powerful multi-dimensional array and matrix data structures along with a massive collection of high-level mathematical functions to manipulate them.



--Why is NumPy so Important?
In standard Python, data collections are typically stored in lists. However, Python lists are dynamic and slow when processing massive amounts of data.

NumPy solves this by introducing the ndarray (N-dimensional array).
